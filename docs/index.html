Continuous Research and Planning Engine

NOETIDE

Research changes the plan. The plan changes the research.

NOETIDE is a deliberation engine for long-running strategy work: persistent user-owned state, explicit evidence, patch-based plan updates, and careful reasoning before execution systems act.

View repository Read the architecture
Why it exists

Most AI tools collapse research, planning, and memory into a conversation.

NOETIDE treats conversation as an interface, not the source of truth. The durable artifact is a strategy graph owned by the user, where evidence, assumptions, hypotheses, decisions, risks, and plan steps remain inspectable across sessions and model providers.

Operating loop

Plans create questions. Evidence changes decisions.

Plan

04

Patch

Update only the affected parts of the strategy instead of regenerating the whole plan.

User-owned state

The strategy survives the session.

NOETIDE stores deliberation as structured state, not hidden chat memory. Model sessions can end, providers can change, and the accumulated reasoning remains available for review, correction, and reuse.

Patches over regeneration

New evidence should touch only what it actually invalidates.

By tracking dependencies, NOETIDE can reconsider the decisions and plan steps connected to a changed claim while leaving unrelated reasoning intact. Corrections become reviewable patches, not rewrites.

Core principles

Built for strategy that keeps changing.

Plans create questions

Planning exposes assumptions, missing evidence, unresolved risks, and contradictions.

Evidence has provenance

Claims can be traced back to sources, observations, and the reasoning they affect.

Execution is downstream

NOETIDE decides what is known, uncertain, and worth doing before execution agents take over.
